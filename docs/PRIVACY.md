# 隐私与权限

[返回项目首页](../README.md) · [停用与撤销权限](TROUBLESHOOTING.md)

HyperKey 的规则在设备上匹配。独立应用未声明 `INTERNET` 权限，项目没有账号、分析 SDK 或遥测上传功能。下表区分长期保存的配置和仅在运行时使用的数据。

| 数据 | 用途与保留方式 |
| --- | --- |
| 全局开关、配置过的应用包名、映射规则 | 按 Android 用户保存在系统 `Settings.Secure` 中，供设置页面和系统端读取。全局单项还会同步到小米原生快捷键库。关闭模块不会自动回滚这些系统设置。 |
| 设备上可启动的应用名称、图标 | 在选择应用时，由 Android `PackageManager` 在本机查询 `MAIN/LAUNCHER`。没有申请 `QUERY_ALL_PACKAGES`；找不到的应用可以手动输入包名。 |
| 前台窗口、输入事件 | 系统端根据键盘焦点的包名和当前按键决定是否执行本机动作或应用映射。按键测试只展示该测试页面收到的事件，最多 16 条，保存在内存里，清空或离开页面后删除。 |
| 语言、主题、强调色 | 独立应用在本机 `SharedPreferences` 中保存。应用清单关闭了 Android 应用备份。 |
| 运行诊断 | 模块记录本次启动的加载状态、已安装 Hook 数等信息，出错时可能写入系统或框架日志，便于排查兼容性。 |

`WRITE_SECURE_SETTINGS` 用来让独立应用保存配置。只使用系统设置中的原生全局开关，无需向独立应用授予此权限。LSPosed 作用域则决定哪些系统进程加载模块，两者作用不同。可核对[应用清单](../app/src/main/AndroidManifest.xml)及[作用域列表](../app/src/main/resources/META-INF/xposed/scope.list)。

公开反馈只需附与问题直接相关的少量信息。请遮挡截图中的通知、账号、设备标识和无关应用名称；不要上传完整日志、应用名单、LSPosed 数据库、系统配置备份或固件文件。
