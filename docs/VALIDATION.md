## 双向同步和实体按键

1. 在 HyperKey UI 开启“回到桌面”。共享配置变为 `1:43ef:0`，系统原生 type=4 的 enable 变为 true；专属原生页面的对应开关显示开启。
2. 对 `/dev/input/event7`（经 getevent 确认为 Xiaomi Keyboard）注入 Meta+D，正确附带 MSC_SCAN、SYN 与抬键。前台从专属快捷键 Activity 变为小米桌面。此处未使用被模块排除的虚拟 `input keyevent` 来声称实体键盘验证成功。
3. 在专属原生页面关闭该项目。共享配置恢复 `1:43ff:0`，HyperKey UI 对应开关关闭；重复实体设备节点注入，前台仍是专属快捷键 Activity。
4. 通用键盘页面显示相同的关闭状态。在该页面开启 HOME，再打开总禁用，配置为 `1:43ef:1`。原生 HOME 仍保存为 true，但页面单项开关变灰不可操作。Meta+D 不返回桌面。
5. 在通用页面解除总禁用，配置恢复 `1:43ef:0`，再次 Meta+D 成功返回桌面；HyperKey 单项仍为开启。
6. 在 HyperKey 关闭 HOME，恢复测试前的 `1:43ff:0`。比较系统 `/data/system/miuishortcuts.xml` 与测试前备份，内容完全相同。
