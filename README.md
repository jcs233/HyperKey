# HyperKey

适配小米 HyperOS 实体键盘的 LSPosed 模块，使用 libxposed API 102 和 Compose Miuix。

提供总禁用开关、19 项独立控制、按应用区分的快捷键名单，并在系统设置中使用宿主原生 Miuix 控件。

## 安装与使用

1. 按下方“编译”生成 APK，然后执行 `adb install -r app/build/outputs/apk/debug/app-debug.apk`。
2. 在支持 API 102 的 LSP 中启用 HyperKey，并选择三个作用域：
   - 系统框架：`system`
   - 设置：`com.android.settings`
   - 系统安全组件：`com.miui.securitycore`
3. 重启设备。
4. 若需使用独立 HyperKey 应用修改配置，执行：

   ```shell
   adb shell pm grant io.github.hyperkey android.permission.WRITE_SECURE_SETTINGS
   ```

系统设置中的开关直接使用宿主权限，无需以上独立应用授权。安装包使用开发调试签名。

## 0.2.0 应用名单

在模块首页或系统键盘页面的“模块管理 → 应用名单”添加应用。支持搜索有启动入口的应用，或输入完整包名添加其他应用；最多 128 项。

- 每个应用可选择全部允许、全部禁用或逐项自定义；未覆盖的单项实时跟随全局。
- 可以暂停单个应用配置、将某项恢复为跟随全局，或移出名单。
- 名单按当前获得键盘焦点的窗口所属包名匹配；分屏时跟随键盘焦点。
- 全局“关闭所有系统快捷键”优先于全部应用配置；解除后恢复各应用选择。
- 名单中的允许项可以覆盖全局关闭的单项。切换应用只改变内存中的处理结果，不修改原生配置文件或全局开关。
- 此功能区分现有系统快捷键的开关，组合键映射沿用小米专属键盘设置；单项开关与下方独立的按键映射功能可分别配置。

升级后需重启设备加载新增系统 Hook。应用名单编辑页使用独立应用权限，需要上述 ADB 授权；即使从系统设置打开该页，也需要此权限。

## 按键映射与 Win 透传

模块首页的“按键映射”编辑全局规则；应用配置中的同名入口编辑应用专属规则，同一来源优先使用应用规则。先录入来源，再选择“目标按键 / 组合键”或“目标系统动作”，检查预览后保存。支持录入实体按键或组合键，输出为另一个按键/组合键，或指定系统动作。相同来源保存会替换原规则，输出不再递归匹配。按键映射仅针对实体字母键盘，不改动触摸键盘、电源和系统导航键。

系统动作包括桌面、最近任务、截屏、锁屏、搜索、窗口操作和通知/控制中心；Alt Tab 会话、任务键手势及批量启动应用不作为映射目标。动作映射提供额外触发组合键，不删除系统原有组合键；若要只保留新组合键，可以关闭原快捷键单项。总禁用会屏蔽映射的系统动作，但保留按键到按键的映射。

应用配置可单独开启“Win 原始按键透传”，把 Win 单击、按住及组合键交给该应用，并阻止对应本机动作，适合远程桌面。总禁用或三个任务键动作全部禁用时也会放行原始 Win 事件。模块首页的“按键测试”用键帽显示组合键和 Android 键值，按住时高亮，松开后保留上次组合。下方最多显示 16 条按下、松开和重复事件，含扫描码及修饰位。离开页面后清除；系统 Hook 生效时，测试页单独接收实体 Win 和 Win 组合键，普通应用的规则不变。远端是否接收，还取决于远程客户端的键盘捕获选项及远端系统配置。

暂停应用配置会暂停其专属映射，仍可使用全局映射；移出名单同时删除该应用专属映射。

## 语言与外观

模块首页“语言与外观”提供跟随系统、简体中文和 English，其他系统语言回退为英文。中英文使用完整 Android 字符串资源，系统设置注入项跟随宿主语言。

主题可跟随系统或固定浅色/深色；可选 Miuix 默认色、系统壁纸强调色（Android 12 以上，取决于系统主题）、Material Design 的 9 种色相 × 3 档色阶（200、500、700），也可以手动输入六位 HEX（可省略 `#`）。色块和输入共用预览，点“应用”才保存；文字根据底色自动选择对比色。设置在所有 HyperKey 页面间生效。原生系统设置保持宿主 Miuix 主题。

## 布局

- 模块主页采用宽屏双列、窄屏单列；大字体下优先使用单列。
- 总开关置顶，通用键盘和小米专属键盘入口集中排列。
- 分组显示开启数量，运行状态和使用说明默认折叠，恢复操作置于底部。
- 专属页面顺序调整为总开关、原生系统快捷键、窗口操作、任务键、其他选项和模块管理。

## 设置入口与同步

- 通用实体键盘页面。
- 小米平板专属键盘页面。
- 专属键盘的“键盘快捷键”原生编辑页。
- HyperKey 独立应用。

原生编辑页属于 `com.miui.securitycore`，因此必须勾选第三个作用域。原生已有的十项快捷键沿用系统控件，缺少的窗口操作、任务键等选项由模块补充。

首次加载保留系统已经关闭的项目。单项开关与原生快捷键库双向同步，启用一项会同时启用系统对应项目；不会重置用户自定义的组合键。总禁用开关保留单项选择，打开时单项变灰，关闭后恢复原来的选择。

控制范围：关闭窗口、两种截屏、锁屏、桌面、搜索、最近任务、Alt Tab、通知中心、控制中心、四种窗口操作、任务键单击/双击/长按、Esc、打开应用。打开应用是聚合开关，会统一启用或禁用全部已有的应用组合键。界面中的组合键提示采用默认布局，原生编辑页可查看和编辑实际组合键。

## 编译

需要 JDK 17、Android SDK 36，以及可访问依赖仓库的网络。

```shell
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Windows 下以 `gradlew.bat` 代替 `./gradlew`。构建输出：`app/build/outputs/apk/debug/app-debug.apk`。

依赖版本固定：libxposed API 102.0.0（compileOnly）、Miuix 0.8.7、AGP 8.13.1、Kotlin 2.3.20。项目不使用旧版 XposedBridge，也不将 libxposed API 类打包进模块。

## 停用

在 LSP 中关闭 HyperKey 后重启，即可停止模块拦截和界面注入。已经同步到原生配置的单项状态仍保留，可继续在小米原生编辑页修改。

设备提取的 APK/JAR、原生配置备份和调试日志位于忽略目录 `device/`，不随安装包分发。
